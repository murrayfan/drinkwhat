## 2. 文件管制

- 文件與程式碼放在同一個儲存庫（`docs/`），隨程式變更一起審查與提交。
- 影響功能、設定項目、外部介接或部署方式的程式變更，須同步更新對應文件並遞增文件版本。
- 版本號規則：內容新增或結構調整遞增次版號（1.0 → 1.1）；全面改版遞增主版號（1.x → 2.0）。

## 4. 名詞定義

| 名詞 | 說明 |
|---|---|
| 轉盤 | 首頁的圓形抽籤盤，每一格代表一間店（GPS 模式）或一個品牌（隨機模式） |
| GPS 模式 | 取得使用者位置後，以附近實際店家作為轉盤選項 |
| 隨機模式 | 不使用定位，從品牌清單隨機挑 6 種作為轉盤選項 |
| 喜歡的品牌 | 使用者設定的偏好品牌，可「只轉喜歡的」或「格子加倍」 |
| 不想喝的 | 使用者設定的排除清單，可排除整個品牌或單一分店 |
| 品牌清單 | `src/data/brands.json`，依 OpenStreetMap 統計的全台分店數前 20 名 |
| OSM | OpenStreetMap，開放授權（ODbL）的社群地圖資料 |
| Overpass API | 查詢 OSM 資料的公開服務 |
